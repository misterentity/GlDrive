# GL Drive v3.19.1

This corrective release addresses faults found in the production logs and the previous release's CI run.

- **AI settings persist and reconcile correctly.** The commit journal now uses the same JSON preparation as the settings writer. Omitted default blocks and preserved hook formatting no longer cause a successful save to be reported as a failure. Pending v3.19.0 commits are reconciled only when the saved configuration proves the exact intended candidate; conflicts remain retained.
- **Temporary login holds pause the affected FXP endpoint.** The scheduler respects the account's retry time, retains the normal bounded wait, and leaves unrelated routes eligible. A setup hold does not consume file retry budgets or poison a clean peer connection.
- **Reliable test teardown.** The IRC alert test awaits the router's final save before deleting its temporary directory, fixing the intermittent CI failure.
- **Release checks are enforced.** Publishing requires clean source matching the pushed commit and successful CI for that commit. Both CI and the standard release script compile the native FTPS/WinFsp smoke harness; its runtime scenarios remain a separate local release check.

The release deployment report records the retained-log audit, test counts, native and UI smoke results, signed package verification, production observation window and external service limitations.
