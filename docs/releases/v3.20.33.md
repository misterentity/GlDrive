# v3.20.33

## Fixed

- **Race queue rows that no button could clear.** When GlDrive gave up removing its own incomplete upload
  from a site (six failed attempts), the request stayed in the queue marked "manual attention required",
  but "Clear queue" and "Remove selected requests" both skipped it and nothing else ever retried it, so it
  sat there indefinitely. Both buttons now remove these rows. Nothing is deleted on the site: the incomplete
  folders stay where they are, the status line says how many, and each path is written to the log.
  Requests whose cleanup is still retrying are kept as before.
