# GlDrive v3.10.90 release record

## Findings and root causes

- Retained production logs for 2026-08-29 through 2026-08-31 contained no `ERR` or `FTL`
  records. The elevated records were availability warnings: the SYN FTP endpoint is unreachable
  even by a direct TCP probe, and intermittent FXP `425` data-channel refusals recovered on the
  existing retry path. Windows Application events contained no current GlDrive crash.
- The latest `master` CI run had one failure out of 1,085 tests:
  `Update_authorization_is_bound_to_staged_file_manifest`. It occurred only on a fresh runner.
- Root cause: `UpdateMarkerHmac.GetOrCreateKey` used an unsynchronized check-then-write. Parallel
  cold-start callers could generate different DPAPI keys and overwrite the same file, making a
  marker written with the losing key fail its immediate validation.

## Changes

- Serialize in-process key initialization.
- Publish a new encrypted key through a same-directory atomic rename.
- If another process wins creation, read and use its key instead of overwriting it.
- Preserve corrupt-key self-healing through atomic replacement.
- Add a 32-caller cold-start regression test that requires one stable persisted key and no
  orphaned temporary files.

## Validation

- Targeted concurrency regression: 21/21 passes (one build run plus 20 no-build stress runs).
- Release build: 0 warnings, 0 errors.
- Full regression suite: 1,086 passed, 0 failed, 0 skipped.
- NuGet audit: no vulnerable direct or transitive packages.
- Self-contained publish: 1,149 files, 349.3 MB.
- Installer/package build: `GlDriveSetup-v3.10.90.exe` (91 MB) and
  `GlDrive-v3.10.90-win-x64.zip` (154.1 MB).
- Package smoke: 1,156 ZIP entries; all required startup and update-task files present.
- UI smoke: the published executable completed `--screenshots` with exit code 0 and rendered
  all 15 expected dashboard, settings, and wizard images. Representative images were visually
  checked for layout, content, and theme integrity. The production process IDs were unchanged.
- Documentation freshness and diff checks passed.

## Release

Version: **3.10.90**

Published from commit `f74225dd406ce6b2d0934c61efd926505d23d81c`. CI and release packaging
passed, but production deployment exposed a separate SYSTEM scheduled-task entry-point defect:
the task exited before consuming its signed hand-off. No installed files were changed. This
release was superseded by v3.10.91 rather than being promoted to production.

## Remaining risks

- SYN remains externally unreachable; GlDrive's bounded remount loop continues to handle it.
- Remote FXP endpoints can still refuse transient data connections; observed failures recovered
  on retry, so no application change was warranted.
