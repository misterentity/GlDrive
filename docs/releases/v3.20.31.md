# v3.20.31

## Fixed

- **Lists and grids scroll smoothly.** Every list and grid scrolled a whole row at a time (three rows per
  wheel notch) while settings pages and text panels scrolled by pixels, so movement was jumpy and differed
  from screen to screen, and the scrollbar thumb resized as rows of different heights came into view. All
  lists and grids now scroll by pixels, the same as everything else.
- **Drop-downs show the selected item's name.** The Plex server picker (and any other drop-down that lists
  objects) showed an internal type name once closed instead of the selected entry.
