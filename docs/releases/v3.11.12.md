# v3.11.12 — hacker-terminal UI and search publication

Claude implemented the industrial hacker-terminal design review using Claude Code
with model `claude-opus-5-5`. Codex independently reviewed the changes and owns
build, test and release verification. Claude's original implementation reports,
restricted tool invocation records and follow-up findings are retained in local
release evidence.

## Interface

The Cyberpunk theme uses compact monospace navigation, graphite surfaces, sharp
controls and restrained mint/lime accents. Release names highlight metadata and
groups while keeping the original strings for sorting, copying and identity.
Download rows show explicit status glyphs, colored rails and progress, and a
visible selection fill and border. The toolbar groups selection actions, a Clear
menu with all four existing cleanup commands, and queue movement controls.

Overview and race cards share segmented meters and filled telemetry charts with
the stream matrix. Active stream details open automatically while respecting a
manual collapse. IRC status shares the footer; empty separators and redundant
offline labels are removed. Texture is confined to instrument surfaces instead
of wrapping every application window.

Search filters expose checked states through UI Automation. Keyboard focus has a
separate outer ring, and numeric stream settings have meaningful accessible
names and units. MCP settings distinguish the saved app connection state from
adapter availability, and emphasize the appropriate panel action. The existing
`fmountr` MCP registration identity is preserved.

## Root causes

The production log review found four dashboard search exceptions between
18:01:56 and 18:32:20 UTC on October 15. Search appended observable results while
the bound collection view deferred refresh; the DataGrid's current-item handling
then threw `InvalidOperationException`. An independent STA/WPF reproduction
failed with deferred additions in both empty and populated filtered views.
Ordinary publication retained filtering, current item and selection. The
originating code predates v3.11.11.

Live download events updated textual progress but omitted the bound percentage,
leaving the bar stale until the row was rebuilt. Percentage updates now accompany
live events, clamp invalid ranges and retain the guard against late callbacks
after downloading ends.

The UI review also caught idle charts retaining old colors after a theme change.
This was reproduced in the proposed implementation before release. Existing
charts now repaint from resource-backed dependency properties when the theme
changes, without requiring new data, resizing or rebuilding the window. An
independent red/green bitmap reproduction verified the fix and confirmed that
rendering does not freeze caller-owned mutable brushes.

## Validation

The Release solution build completed with zero warnings and zero errors.
All 2,290 regression tests passed (2,270 application and 20 MCP), with no failures
or skips. The focused UI run passed all 68 selected tests, including real control
selection, live progress, filter automation, clear-menu commands, search
publication, keyboard focus and live theme changes.

The candidate passed 87 native FTPS/WinFsp smoke assertions. Its owned loopback
fixture stopped and was removed, and the machine's logical drives were unchanged.
The v3.11.12 renderer produced all 60 expected fresh screenshots; normal and
narrow Downloads, Search, Overview, Spread, MCP, Streams and matrix views were
reviewed. Protected user state and the running production processes were
preserved. The dependency audit found no vulnerable direct or transitive
packages in the four solution projects; this release changes no dependencies.

An independent native-input harness verified keyboard focus rings and Space
activation in all three themes. The initial synthetic-key test moved focus but
bypassed WPF's most-recent-input-device tracking; Claude corrected the fixture
to deliver native messages only to its own test window, retaining the assertions.

## Remaining limits

Existing local dashboard styles can retain their initial font or row density
until that window is reopened after a theme switch; the new colors and helpers
update live. The narrow matrix has tight spacing between one lane and network
label, with trimming/tooltips available. Neither prevented reviewed workflows.

Remote SYN connectivity, incomplete source archives and low free disk space
remain environment/input risks. Loopback smoke tests do not replace a remote
BNC/CPSV exercise or a multi-hour soak. Existing MCP hosts can retain older signed
backup files until they exit. The installer retains its existing Inno Setup
admin/HKCU `UsedUserAreasWarning`.

Two small temporary Git verification directories remain because automatic
approval review blocked their cleanup with the reason "blocked by policy".
They do not affect the application or release artifacts.
