## Cleanup: shared helpers and storage

- Title keys, season/episode tokens and the release-name plausibility check now each live in one place in GlDrive.Core. Full-width and ligature titles now get the same key in the wishlist and the library index. Lower-case ranges like `s01e01-e03` are read as episodes 1-3.
- One byte/speed formatter for every screen.
- One long-lived TMDB, OMDb and TVMaze client each. A changed OMDb key now reaches race filters without a restart.
- Retired the legacy REST control routes (`/status`, `/races`, `/history`, `/sections`). MCP uses the automation routes, which keep the same token and scope checks.
- Addline offers, PM history and IRC unread counts share one encrypted-file helper. PM history and unread counts now write through the safe atomic writer with permissions set first.
- Startup removes leftover `<file>.<id>.tmp` files from interrupted writes (older than 1 hour, top level of `%AppData%\GlDrive` only).
- Removed the unused feed-preferences guard layer. `guardFeedPreferences` in old configs still loads.
- One FTP directory maker for races, manual directory FXP and Browse; Browse now sanitizes the path it sends.
