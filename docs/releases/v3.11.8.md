# v3.11.8 — resume incomplete watched archives after restart

## Changes and root cause

This follow-up completes the October 14 log review and release validation begun
in [v3.11.7](v3.11.7.md), including its statistics-refresh contention fix and the
historical crash, pool-remount and updater investigations.

Postdeployment review found a recovery defect in watched-folder extraction. On
restart, an unchanged archive with a persisted abandonment record was added to
the duplicate-event set but not to the in-memory revival ledger. When another
volume arrived, the durable record could expire while the duplicate-event set
still blocked extraction; the periodic recovery sweep did not see that archive
either. Durable skips now seed the revival ledger, allowing new or resized
volumes to clear stale duplicate/retry state and resume through the normal path.
Unchanged or unreadable archives remain parked.

This defect is separate from the two warnings that prompted the deeper review.
Those were stale, single-volume archives unchanged since April/August, with no
sibling volumes or SFV manifest. Their September 14 abandonment records reached
the deliberate 30-day expiry on October 14. The v3.11.7 startup retried each once,
confirmed incomplete multipart input and recorded the unchanged fingerprints
again. Those failures do not establish new file corruption or a transfer defect.

  a real persisted store and invoke the production skip and watcher methods for

  they do not claim full decompression or execution of the periodic timer.

  **2,167 application tests and 20 MCP tests passed**, none failed or skipped.

  The fresh baseline verifies 1,346 signed v3.11.7 files and carries forward

## Remaining risks

SYN FTP remains unreachable before authentication. One remote release and an
incomplete local archive await missing parts; two other stale local archives
lack continuation volumes. Existing input is preserved. D: had 272.54 GiB free
(3.66%) at audit time. T: is absent with no current parked download. Existing MCP
hosts retain old mapped files until they exit and cleanup can remove them.
Native loopback tests do not emulate every glftpd/BNC/CPSV behavior; rendered UI
smoke uses demo state. Bounded health monitoring is not a long soak or an
independent checksum audit of remote content.
