# GL Drive v3.15.2

Fix source discovery for merged race announcements, including requests restored
after an update. Production monitoring of v3.15.1 exposed this pre-existing defect.

A pathless announcement could be turned into a guessed source directory and
inserted into the known-path table before discovery. The normal search then
skipped that server, even though the release existed under its configured recent
or incoming directory. The race could fail with "no viable transfers" without
copying anything.

Merged hints now participate in bounded source discovery. Pathless and stale hints
cannot suppress normal candidate-path probing; restored destination ownership
remains pinned. Sources announced during startup are also verified before a
missing-source verdict; unavailable probes remain inconclusive. Loopback
regression tests exercise the actual startup path and
verify that source discovery does not create, upload, download, or erase content.

This release also includes v3.15.1's remount scheduling, timed-setting ownership,
and native test-isolation fixes. The deployment report records final validation,
signed package verification, recovery of affected queued requests, and production
observation.
