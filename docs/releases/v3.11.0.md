# GlDrive v3.11.0

GlDrive now includes a local MCP server for Claude Code, Claude Desktop, and Codex. Enable **Settings → Diagnostics → Enable MCP / local control API**, save, then register the packaged `mcp/GlDrive.Mcp.exe` with your client. See [MCP setup](../mcp.md).

The live catalog exposes configuration and credential management, server mounts, FTP reads and writes, search, downloads, wishlists, notifications, IRC and FiSH, racing and FXP, Plex, player controls, extraction, cleanup, diagnostics, AI controls, snapshots, certificate pins, updates, and the glFTPd installer. Tools use the running app's services. Long operations return job IDs for progress and cancellation.

The adapter uses the official MCP SDK over stdio and connects only to the authenticated loopback API. It starts while the app is offline and refreshes its tools after reconnection. The adapter ships with its own .NET runtime in both installer and update zip.

Credentials are redacted by default, writes are validated, and settings use atomic persistence with revision checks. Configuration reads use the latest persisted settings so detached AI saves are not overwritten by stale runtime state. Existing client tokens are preserved during snapshot restoration. Runtime setting changes may require an app restart.

Embedded third-party web pages remain outside the app API. Authentication may require a browser, and remote FTP/IRC/Plex/SSH operations still require configured, reachable services. Installer automation requires a verified SSH host key and a fresh `/glftpd` destination. Cancellation is cooperative and never rolls back completed effects.
