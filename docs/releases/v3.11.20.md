# GL Drive v3.11.20 — release-directory rule covers music and game names

## What production showed after v3.11.19

v3.11.19 stopped the search crawlers from listing inside scene release directories, but it
recognised a release only by a digit plus `.`/`_` separators. Within 11 minutes of the
3.11.19 deploy, superbnc had listed 632 release directories under `/recent` anyway:

- 492 hyphen-only music names, such as `KUKO-CATHARSIS-16BIT-WEB-FLAC-2026-WAVED`
- 140 game names with no digit, such as `A_World_to_Come-bADkARMA`

Zephyr's index was correct straight away. It was built 10 seconds after mount, and its
releases, including boxset contents, were all still searchable. Its `Sample` entries fell
from thousands to 8. superbnc's index still had not finished.

The 3.11.19 rule was a list of features from the names it was written against. It did not
capture the property that separates a release from a container.

## Rule in v3.11.20

`IsReleaseDirectory` now requires:

- no whitespace
- a trailing `-GROUP` tag made of word characters that contains a letter
- at least three `.`, `_` or `-` separated tokens

Every superbnc release directory the old crawl listed on 2026-10-16 (20,714 names taken from
the protocol log) was replayed through the new rule:

- 20,660 are recognised as releases.
- The other 54 (0.26%) are still listed, as they were before 3.11.19. They are digit-only
  groups (`-401`, `-403`, `-404`) and two-token game names (`Cairn-bADkARMA`, `BLACKWOOD-RUNE`).
- All 20 real category folders (`tv-hd`, `x264-hd`, `bluray-uhd`, `xxx-paysite`, `tv-sports`
  and the rest) stay containers.
- Boxsets (`007.Boxset`, `Kick-Ass.Boxset`), date folders and names with spaces are still
  descended.

## Tests

- Release cases now include the production music and game names. Container cases now include
  `tv-sports`, `xxx-paysite` and `TV-SORTED`. The crawl test mixes underscore and hyphen-only
  music names.
- Mutation-verified:
  - Lowering the token minimum to 2 makes the category containers fail.
  - Dropping the group-letter check makes the date and year-range containers fail.
  - The call-site guards from 3.11.19 are unchanged and remain covered.
