# GL Drive v3.20.35

When a source moves a release between two directories during an FXP transfer, GL Drive now checks the alternate directory for the file that failed before switching to it while both directories remain visible. A delayed failure from the previous path can no longer redirect the current transfer source.

The change addresses a production race that switched directories three times while the remote server moved the files. Remote directory filters, FTP session timeouts and missing payloads can still prevent individual transfers. The fix preserves the existing recovery path when the original directory disappears.
