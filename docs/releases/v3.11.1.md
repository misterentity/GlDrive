# GlDrive v3.11.1 — STREAM MATRIX

v3.11.0 shipped multi-stream / multi-network downloads, modelled on [plexo](https://github.com/anmolkapil/plexo). This release adds their cyberpunk live view and a dedicated settings tab.

![Stream matrix](https://raw.githubusercontent.com/misterentity/GlDrive/v3.11.1/docs/screenshots/multistream-matrix.png)

## What's new

- **STREAM MATRIX** on the Downloads tab, for the selected download:
  - a segment grid coloured by the lane (connection/network) that fetched each block, with glowing write heads and resumed bytes marked as cached;
  - a lane table showing state, rate and bytes;
  - a 60-second throughput sparkline with per-lane lines;
  - a `⚙ CONFIG` button that jumps to the settings.
- **Lane chips** on every download row, e.g. `ETHERNET 29.8 MB/s`, `RACE LOGIN 17.4 MB/s`.
- **Settings → STREAMS & UPLINKS**, one place for:
  - multi-stream on/off and borrowing the idle race login;
  - HTTP lanes per network and the FTP minimum split;
  - the global speed limit and Slow mode;
  - your uplinks, with alias, KB/s limit, data allowance and period, a usage bar and a reset.

![Settings](https://raw.githubusercontent.com/misterentity/GlDrive/v3.11.1/docs/screenshots/multistream-settings.png)

## How multi-stream works (recap)

- **FTP:** your normal download connection, plus the site's race login while that site isn't racing. The race login is handed back within about a second when a race wants it, so racing is unaffected. CPSV sites only.
- **Combining internet connections:** tick two or more uplinks (e.g. Ethernet plus a phone tether). Downloads use the default route only until you do.
- **Safer resume:** files download as `.gdpart` and are resumed only against the same remote version. They take their final name only after the server confirms end of file.

## Fixes

- The ETA no longer overflows during a stall, which used to freeze the matrix.
- A late progress report no longer brings back a finished download's matrix.
- The uplink table stays readable at the Settings window's minimum width.
- Includes the project-review fixes already on master: transfers, mounts and AI settings.
