## Updater split and crash attribution

- The elevated updater process code moved out of `UpdateChecker` into `UpdateInstaller` (plus `UpdateChecksumSignature` and `UpdateMarkerHmac` in their own files). No behaviour or log text changes.
- The watchdog now attributes a .NET/WER crash event only to the GlDrive process that actually crashed, instead of any GlDrive-related crash event in the last 30 seconds.
