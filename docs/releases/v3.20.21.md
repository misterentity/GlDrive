# GL Drive v3.20.21

Race queue controls on the Spread tab, in the AUTO RACES header.

- **CLEAR QUEUE** removes every race that has not started. Running races
  continue.
- **STOP ALL** stops every running race and removes every queued one.
- A race you stop (with either Stop button or STOP ALL) now leaves the list
  instead of staying as a STOPPED card. It remains in race history.

Both buttons use the existing 10-second Undo slot before anything is removed.
Queued requests that are starting, or that already uploaded files and still
need their cleanup, are kept and counted in the status line. No content is
deleted on any site. Announces that arrive afterwards queue as usual.
