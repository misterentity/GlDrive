The skip decision itself is unchanged: it was correct.

## Remaining risks

- SYN FTP host is still unreachable, so its races and mount keep failing. This needs a server-side fix.
- `T:\` is not mounted, so the Backrooms BLURAY download parks every hour. The operator needs to mount the drive or change `downloads.localPath`.
- zephyr has no tv-sports section, so tv-sports announces can never race. This is a configuration decision; this release only makes it visible.
- superbnc→zephyr 425 refusals (about 1% of transfers) are server-side. Existing retry policies handle them.
- The change only affects a log/UI string. There are no schema or persisted-state changes. Roll back with the v3.10.121 installer if needed.
