# GL Drive v3.19.9

Successful standard FTP directory listings now keep an existing CPSV compatibility
fallback active. An ioFTPD site that has been listing successfully no longer switches
back to an incompatible data-TLS mode merely because six hours have elapsed since
the original detection. That retry previously failed a listing and quarantined a login.

The fallback still expires after six hours without a validated standard listing.
Failed, cancelled or incomplete listings do not extend it, and ordinary PASV servers
do not acquire a fallback. Existing safeguards for proven glftpd peers remain intact.

Regression coverage includes advancing-clock compatibility tests and real local
FTPS checks for empty successful listings, rejected listings and refused data sockets.

Applying settings also preserves lists that background operations are reading.
A notification-only edit previously cleared and repopulated search paths, causing
an in-progress index refresh to fail with "Collection was modified". Settings now
use the shared reconciler, and each search keeps its starting paths and depth for
the duration of that operation. Subsequent searches use the updated settings.
