## Idle-reaped logins are not outages

sitec closes any login idle for 300 seconds and does not count NOOP as activity. The
connection monitor NOOPed a pooled login every 30 seconds, so every login was reaped
anyway; the next probe got `421 Timeout (300 seconds)` and the monitor declared the
whole server lost — 250 false outages over November 8–9, each costing a fresh login,
and one exhausted the account's login budget for three minutes.

- Keepalive and pool liveness probes send `PWD`, a real command every server counts.
- One failed probe now proves only that one pooled login is dead. The monitor re-probes
  on a freshly borrowed login and declares the server lost only if that fails too.
  Borrow failures (login cap, cooldown) still propagate without an extra login.

## Accurate auto-race skip reason

When rules denied a release on every site, the skip was logged as "no configured
server has section [tv-hd]". It now names the denials: "denied on every server (…)".
