## Changes

`SerializedGnuTlsStream` now has one atomic disposal owner. When native I/O
outlasts the bounded synchronous wait, an asynchronous waiter retains the owner
and frees the native session only after obtaining the same lock held by the
actual read/write. Deferred cleanup marks the stale transport unusable before
disposal, avoiding a graceful native close against a socket FluentFTP may have
closed. New I/O is rejected immediately; already queued operations recheck after
acquiring the lock. Cleanup exceptions are observed and logged, without retrying
a partially completed native disposal. Normal quiescent/in-budget close and TLS
control-session resumption retain their behavior.

`SpreadJob` timeout attribution now excludes a peer connection already acquired
by that transfer and uses the account gate's effective pool capacity. The
diagnoser no longer treats empty/below-capacity counters as proof of ghost
sessions or cross-pool login contention, and no longer advises a destructive
`!username` login without evidence. Unborrowed counters may represent connection
establishment; wording preserves that uncertainty. Borrowing, transfer retries,
permit ownership, poisoning, and remote-outage policy are unchanged.

Independent review found and resolved an intermediate diagnostic overstatement
(`Active < Created` does not guarantee an idle connection). Final review found
no blocking issue in the diagnostics or native lifetime changes. The stale
helper comment describing permanent leakage was also corrected.

  connection resets, PreDB availability, and provider rate limits remain external
  dependencies; fixes do not guarantee those events disappear.
- A native operation that never returns must still retain its session to avoid
  freeing state under a live native call. The fix reclaims sessions after I/O
  actually drains; it does not forcibly interrupt wedged native code. Deterministic
  fault tests and native smoke do not replace a sustained remote-fault soak.

  cutoff **October 23 20:00:47 local** to midnight is not reconstructable from
