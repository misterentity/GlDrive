## Change and validation

Release commit `cc164f76ee5a3b2badceebf183801d7c9d5f2f2e` preserves the FTP 421 response code during CPSV listing setup. Notification polling uses that code to retry a read after the closed connection has been discarded. This applies to watch-root and category listings. Four regression cases exercise recovery at each level, the retry limit on repeated 421 responses and immediate propagation of a 550 refusal.

The locked Release build finished with zero warnings and errors. All 6,309 regression tests passed with zero skips (6,145 application, 140 Core, 24 MCP). All 12 notification-monitor recovery cases also passed in a separate focused run. The native suite passed 176 FTPS/WinFsp assertions and 96 CPSV/login-sharing assertions, restored its drive letters and removed its fixture. The UI smoke verified the manifest, sizes, hashes and nonblank pixels of all 64 expected views.

Before publication, the installed v3.20.35 passed four FTP root listings and three enabled IRC status queries. Its diagnostics also reported six unavailable announce-channel mappings and five frozen decisions awaiting operator review. The retained daily logs before the incident window contained no error or fatal entries.

Detailed local evidence is in `.release-tools/review-20261127/`. It includes private machine and queue data.

## Production observation

From 16:19:50 to 16:25:06 UTC, all eight process, heartbeat, connection and authenticated automation health samples passed with one process ID. The final read-only smoke again passed all four FTP roots and three enabled IRC connections. Retention checks accounted for all 125 application records. There were zero error or fatal records and zero matching Windows Application events.

**The strict production monitor failed its job-outcome check.** Seven spread jobs started, and all seven failed after the destination refused directory creation. The trace contained 14 explicit server refusals. These jobs still require an eligible destination that permits the upload. All four notification monitors seeded. No notification poll warning recurred during this short window, so the focused regression tests provide the evidence for recovery from an actual 421 response. Production observations cover this Windows installation only.
