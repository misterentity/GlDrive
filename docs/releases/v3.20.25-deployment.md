## Changes

1. **Date containers entered the release pipeline.** Polling accepted category
   children named `MMDD`, generating nine notifications and three invalid queued
   races that later failed source discovery. Valid four-ASCII-digit calendar
   containers are now excluded before notification, wishlist and race consumers.
   Ordinary short names and names containing dates retain their prior behavior.
   The existing queue was checked: none of its 125 captured entries was a valid
   `MMDD` container, so no queue entries were removed.
2. **Request permissions spread to ordinary participants.** A request could promote
   an ordinary queued race, and an ordinary duplicate announce could add receivers
   to a request fill. Ordinary work now retains its original policy; requests
   defer admission without spending transfer-failure attempts. Request receivers
   are restricted at admission, transfer scheduling and completion, including
   older persisted fills. Source hints, hourly limits and age limits remain active.
3. **The directory walker could recreate a vanished request parent.** Request
   creation now first requires that exact existing parent, then creates only the
   release and its descendants. Failed or ambiguous replies remain failures;
   synchronized refusals retain their actual FTP reply and safe session handling.

The request defects were identified during the preceding source review and
reproduced with regressions here. They are not claimed as the cause of the baseline
music-category permission failures: none of the 3,078 detailed denial records
involved a REQUEST path.

## Remaining risks and limits

- The remote reply `Error: Not allowed to make directories here.` requires a
  destination-owner decision: grant the intended directory rights or supply an
  approved existing-directory route. No remote permissions, credentials, login
  limits or configuration mappings were changed to silence failures.
- Missing remote content, stalled transfers, idle disconnections and incomplete
  indexes remain possible. Successful intervening polls do not explain why each
  remote session expired. Severity alone is not a clean-health acceptance gate.
- Polling remains one level below each category. It does not recursively traverse
  historical date buckets; any legitimate bare name equal to a valid `MMDD` is
  excluded from automatic polling. Manual transfer remains available.
- FTP cannot make the parent `CWD` and subsequent directory creation atomic with
  a server-side rename. The fix verifies the boundary immediately before walking
  and never issues a creation command for that parent or its ancestors.
- Existing announce-channel configuration and frozen-agent notices require
  operator intent. The prior unconfirmed intermittent cancellation/resume and
  keyboard-test observations remain historical risks unless reproduced here.
- The EXE installer's optional HKCU autostart behavior under another account's
  elevation remains an existing installer limitation; the signed ZIP updater does
  not execute that registry section. See the prior deployment report.
- Disposable FTPS/WinFsp fixtures cannot reproduce every remote setup. UI demo
  rendering does not establish playback, and verified backup files do not
  constitute an executed rollback.
