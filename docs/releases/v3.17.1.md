# GL Drive v3.17.1

A fix for the Spread tab.

- **CLEAR DONE clears finished race cards immediately again.** v3.17.0 sent it through the same 10-second Undo slot as destructive bulk removals. The cards stayed on screen during the countdown, which was shown only in a bar at the bottom of the window. Closing the dashboard within those 10 seconds silently dropped the clear. While any other removal was pending, the button did nothing at all.
- Finished cards are only a view of completed races, and clearing them never touches race history. So CLEAR DONE now behaves like DISMISS, and the Spread status line confirms how many cards were cleared.

## Release tooling

- Two UI render checks need an unlocked, interactive desktop: real keyboard focus with native Tab delivery, and live repaint after a theme swap. They couldn't pass on a locked workstation, which failed unattended release runs. They are now skipped there, and still run on every unlocked run.
