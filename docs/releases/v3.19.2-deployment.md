## Findings and corrections

| Finding | Root cause and evidence | Resolution |
|---|---|---|
| Sitebot notices and prose became "new releases" | zephyr `#ent` rule `(?<section>\w[\w-]*)\s*:\s*(?<release>\S+)` matched `AUTONUKE: TV/Nocturne.2026.S01E01.2160p.WEB.H265-CAKES created by altruist is still empty…` as section `AUTONUKE`, release `TV/Nocturne...`. The `#SYN-SPAM` catch-all matched a plot synopsis as `Frankenstein,`. `IsPlausibleReleaseName` accepted both: it checked only length, a verb list and a structural token. Each false match was counted as sitebot activity, recorded as an AI section-learning signal and offered to auto-race. (Auto-race declined both only because the section did not exist.) | The shared gate now requires the defining property: one directory name ending in its group tag. It rejects filename-illegal characters (path separators, `:`, `?` and so on) and a final character other than a letter, digit, `)` or `]`. Against **2,350 distinct real release names** from three days of logs and race history, exactly these two were rejected. The gate also covers race pulls, wanted acquisition and the wanted index sweep. |
| CI failed intermittently in `HookRunnerTests` | Teardown `Directory.Delete` failed with "used by another process" in CI runs 40787794556, 40995764750 and 40996827934. The first hypothesis was that the killed hook parent was still terminating, so a bounded wait was added to `HookRunner` (`07c8ec4`). Run 40996827934 failed **after** the test had asserted both parent and child had exited, which disproved it. The change was reverted (`0977b19`), so no unproven runtime change ships. | Fixture teardown retries the delete for up to 10 s. The product assertions (timeout outcome, bounded output, killed child tree) had passed in every failing run. The exact process holding the folder on the CI runner was not identified. |

## Remaining risks and limits

- **No race ran in the watch window** (quiet hour). FXP racing on 3.19.2 is covered by the unchanged race code, the native smokes and the 5,443-test suite, not by an observed production race.
- **The AUTONUKE fix cannot be triggered on demand.** It is verified by unit tests built from the two real messages and by the corpus check. The next live confirmation is an `AUTONUKE`/`Plot:` line producing no `IRC announce detected`.
- **The broad announce rules remain configured** (zephyr `#ent` `(?<section>\w[\w-]*)\s*:\s*…`, SYN `#SYN-SPAM` `(?<section>\w[\w-]*)\s+…`). The gate now filters their false captures, but tightening or removing the rules is a configuration decision for Dave.
- **SYN FTP outage** continues (external). Next automatic retry 2026-10-30 05:52 UTC.
- **superbnc→zephyr stays relay-only.** The 6-hourly direct re-probe costs two logins each time. The underlying direct-FXP issue is documented separately and needs Dave's decision before `trySourceCpsvDirect` is enabled.
- **Hook test teardown:** the process that briefly holds the folder on CI was not identified, and the retry makes teardown tolerant rather than explaining it. `ExtractorWindow` similarly kills UnRAR on timeout or cancel without waiting for exit, but nothing in the logs shows that path causing a fault.
- A 12-minute watch is not an extended BNC soak.
