# v3.20.34

## Added

- **Download a release from several sites at once.** With "Download from multiple sites" on
  (Settings → Streams & uplinks, off by default), a download also pulls from other mounted sites whose
  search index holds the same release. A copy is used only when its files match the original site's
  checksums (SFV, or the FTP checksum for files outside an SFV), and every file fetched from another site is
  checked again before it is put in place; a mismatch is thrown away and fetched from the original site.
- **Preferred download source.** Pick a site in the same panel and it is tried first for multi-site
  downloads, and wins ties when the wishlist chooses between equally good copies.
