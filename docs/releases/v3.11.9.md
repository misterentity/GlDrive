# v3.11.9 — clearer navigation and more readable screens

This release improves the dashboard, settings, setup dialogs, archive tools, and
AI Agent views, with consistent styling across Cyberpunk, Dark, and Light.

## Improvements

- Clear section headings and guidance, scrollable navigation, useful empty
  states, result counts, and selection-aware actions.
- More readable typography, contrast, table rows, keyboard focus, password
  fields, and selected or disabled controls. Cyberpunk keeps its visual identity
  with a subtler scanline effect.
- Better layouts at smaller window sizes, including wrapping toolbars, chat
  messages, server browsing, network adapter settings, and archive errors.
- Transfer and race diagnostics expand on demand, leaving more room for active
  work. Progress bars reflect their values and status colors correctly.
- Correct connected-server and race counters, clearer completion labels, and
  an Overview screen that loads its status immediately.
- Clearer setup steps and inline validation, metadata search feedback, and tag
  rule editing that respects Cancel.
- Reliable live theme switching without retaining styles from the previous
  theme.

## Validation

- Build succeeded and all 37 focused UI, rendering, and related regression
  checks passed, including switching away from Cyberpunk at runtime.
- Rendered 180 sample-data previews across all three themes, covering normal
  and minimum window sizes, populated lists, empty states, and native dialogs.
- Visual inspection covered representative dashboard screens, settings,
  archive tools, AI Agent views, and all seven supporting dialogs.

The preview checks use sample data. Live remote transfers and media playback
were not exercised as part of this visual review.
