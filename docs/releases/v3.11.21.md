# GL Drive v3.11.21 — reliable search deadlines and tray recovery

## Fixes

- A live search whose listing finished during deadline cancellation could report a
  complete empty result before cancellation reached its linked traversal token.
  Check the deadline token directly, preserving the timeout/partial-result status.
  The regression now forces that callback ordering instead of depending on timing.
- Handle Windows rejecting a tray tooltip update during shell disruption. Preserve
  the latest requested tooltip for the tray library's existing recreation path,
  while allowing unrelated programming errors to propagate.
- Document the clean worktree outside OneDrive required by the release provenance
  guard. The standard signed release pipeline and its checks remain in use.

## Operational scope

The October 17–19 rolling application logs had no error or fatal entries. The
review also included retained historical crash dumps and the prior release's
intermittent timeout regression. External FTP/IRC availability failures remain
outside this release's control; the deployment report records their disposition,
test evidence, package identity, and the production observation window.
