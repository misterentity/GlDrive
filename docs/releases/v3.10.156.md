# v3.10.156 — multi-stream / multi-network downloads

Downloads can now pull a file over several connections, and over several internet connections, at once, modelled on [plexo](https://github.com/anmolkapil/plexo). **This is for downloads only.** FXP racing is untouched, except that a download may borrow a site's idle race login, as described below.

![Stream matrix](https://raw.githubusercontent.com/misterentity/GlDrive/master/docs/screenshots/multistream-matrix.png)

## What's new

- **Two FTP streams per site, without new logins.**
  - Lane 1 is the usual download connection.
  - Lane 2 is the site's race login. It is borrowed only while the site has no active, starting or queued race, and is handed back within about a second when a race wants it (CPSV sites).
  - The lanes mostly take whole RAR volumes, so each file finishes on a clean 226. A file is split only at the tail.
- **Combine internet connections.** Tick two or more uplinks (e.g. Ethernet plus a phone tether) under Settings → **STREAMS & UPLINKS**. FTP binds its data connections to each uplink, while the drive and racing stay on the default route. If no uplink is ticked, downloads use the default route only, so nothing changes until you opt in.
- **Safer resume.**
  - Files download as `.gdpart` and take their final name only once the server confirms end of file.
  - Resume is checked against the remote version (FTP size + MDTM, HTTP ETag/Last-Modified), so a resumed file is never stitched together from two different versions.
- **Throttling.**
  - One total speed limit across every server, plus Slow mode (in the tray), per-server limits and per-network limits.
  - Optional data allowances per network per day, week or month. When every selected network is over its allowance, downloads wait instead of failing.
- **Updates** download over ranged multi-connection HTTP, falling back to a single stream. **Torrents** get the speed caps.
- **STREAM MATRIX** live view on the Downloads tab:
  - a segment grid coloured by the lane that fetched each block
  - a per-lane table and a throughput sparkline
  - lane chips on every download row

## Fixes

- Connection pool: a borrower waiting for a free connection is now woken when a connection is discarded, instead of waiting for one that will never come back.

## Behavior change

- The global download speed limit is now shared by all servers. Before, each server got the full limit.
