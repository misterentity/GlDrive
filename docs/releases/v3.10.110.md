## Change

Relay opens both CPSV data sockets, sends RETR, then sends STOR. If RETR is rejected, STOR
has never been sent. Destination CPSV has already returned its reply, so the destination owes
no transfer reply. Previously `FxpFaultSide.Both` and its pending-sequence marker each independently
caused that healthy destination login to be discarded, costing a 20-second quarantine and a
replacement login against a four-login account cap.

`AcceptRelayRetrReply` now clears only the destination marker and attributes the failure to
the source. The source remains quarantined even for unexpected replies or service shutdown.
Accepted 125/150 replies retain both pending markers; exceptions before a reply arrives bypass
the helper and preserve conservative handling. Data sockets still close in `finally`, and earlier
explicit poison flags from direct-to-Relay fallback remain authoritative.

The protocol distinction follows the command/reply sequencing in
[RFC 959 sections 5.4 and 6](https://www.rfc-editor.org/rfc/rfc959).

## Validation before release

- Baseline: 1,175 tests passed, zero failures or skips.
- Seven added regression cases: four rejection cases failed before the fix; all seven passed
  after it. Cases cover 425/450/550/421, accepted 125/150, both marker states, fault attribution,
  preserved exception diagnostics, and placement before STOR and outside unconditional cleanup.

- Release application build: **zero warnings, zero errors**.

- Existing production API smoke: authenticated `/`, `/status`, `/sections`, `/races`, and

## Remaining risks and limits

- SYN FTP is externally unavailable; production is degraded to two of three FTP servers.
- Remote 425 refusals and transient reconnect timeouts can recur. Retries recovered all four
  observed transfer incidents; this fix reduces collateral connection loss, not remote failures.
- The changed rejection branch needs a natural production trigger for live confirmation.
  Unit regression and rendering checks do not replace a sustained real FTPS race.
- v3.10.109's heartbeat at review showed 284 MB working set after roughly 11 hours; longer
  observation remains necessary to assess memory behavior under sustained traffic.
