# GL Drive v3.20.23

This release fixes the fullscreen player exception and two causes of unnecessary
FTP reconnects found during the application-log review.

- Leaving fullscreen releases the active window reference before closing it, so
  the window's close callback cannot attach the video view twice. Closing the
  dashboard also closes fullscreen before disposing the player.
- Automatic source-search budgets and a competing source result stop further
  search traversal while allowing an issued FTP command to finish. Explicit
  caller cancellation and the existing 90-second hard search deadline remain
  effective. `spread.alternateSourceSearchTimeoutSeconds` limits traversal;
  an outstanding command can finish after that shorter budget expires.
- A confirmed directory-creation refusal during relay setup releases the pending
  data-sequence markers before any transfer command starts. Interrupted commands,
  closing sessions and ambiguous replies retain conservative quarantine.

Remote directory restrictions, unavailable content and server outages can still
cause operations to fail. Login limits, retry bounds, source restrictions and
remote permission policies remain enforced. Existing announce-channel warnings
and frozen-agent notices require configuration-owner decisions.

The deployment report records the regression, native FTP, UI, package and
production verification results, including their observation limits.
