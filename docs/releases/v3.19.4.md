# GL Drive v3.19.4

This release fixes the auto-race skip warning flood found while reviewing the v3.19.3 application logs.

The v3.19.3 process ran 9.5 hours with zero errors, fatal records or crashes. Of its 360 warnings, 355 were the same auto-race skip, one per IRC announce, while zephyr and SYN were unreachable. None of them named the missing sites. Each one suggested a login-cap problem, which was not the cause. The other five warnings were the scheduled 4-hour remount retries for those two sites.

- The skip warning now names the race sites that are unavailable. It suggests checking the login cap only when no FTP pool is live, which is the case that hint was written for.
- The warning fires once when the set of unavailable sites changes, and again hourly while the outage persists. Repeats log at Debug, and each warning reports how many were suppressed. Once two sites are connected again, the next outage warns immediately.
- The auto-race policy itself is unchanged: announces are still skipped while fewer than two race sites are connected.

The application cannot restore an unavailable FTP endpoint. Zephyr (192.168.1.86:2010, a host on the local network) and SYN still did not answer TCP connections during this review. See the [deployment report](https://github.com/misterentity/GlDrive/blob/master/docs/releases/v3.19.4-deployment.md).
