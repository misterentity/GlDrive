Fixes updates rolling back when an MCP host still has files open from a previous release. Each installation now uses unique backup filenames, preserving older mapped files and the current installation's rollback data.

Installer diagnostics are also written to `%PROGRAMDATA%\GlDrive\update-install.log`, including updates run by the SYSTEM scheduled task.

If an older installed updater is already stuck on a previous version, run the full installer once or close the MCP hosts retaining old GlDrive files before retrying. Downloading the new ZIP alone does not replace the older updater that applies it.
