# GlDrive v3.11.2 — MCP settings

Connect Claude Code, Claude Desktop, or Codex from the new **Settings → MCP** panel.

- Enable MCP and choose its local port, then **Apply MCP settings** without closing Settings or saving drafts from other tabs.
- **Check connection** reports whether the app's authenticated local API is reachable and how many tools it exposes.
- Select your client and copy its setup command or JSON. The panel uses the actual installed adapter path and warns if the adapter is missing. Authentication is automatic; no token needs to be copied.
- Invalid ports are rejected, saved credentials are preserved, and failed settings writes leave the running configuration unchanged.

To connect: open **Settings → MCP**, enable MCP, click **Apply MCP settings**, select your client, and copy its command or JSON. Run the command in PowerShell, or merge the JSON into Claude Desktop's configuration. Reconnect the client and keep GlDrive running. See the [setup guide](https://github.com/misterentity/GlDrive/blob/v3.11.2/docs/mcp.md).

The self-contained MCP adapter and setup guide are included in both the installer and update ZIP. This release also fixes CI restore and test coverage for the MCP test project.

Validation: 2,020 app tests and 20 MCP adapter tests passed. The MCP panel was visually checked at normal and minimum window sizes, including the Claude Desktop configuration view.
