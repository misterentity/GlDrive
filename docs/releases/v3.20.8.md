## Cleanup: dead code and AI Setup

- Removed about 700 lines of dead code (unused methods, fields, parameters and test-only wrappers) found by a dead-code review.
- AI Setup and the AI agent now share one OpenRouter transport. Secret redaction runs inside it, so no request can skip it.
- One SITE RULES parser for both Detect Rules and AI Setup, with tests. Banned groups now become deny rules instead of being added to affils (which let them bypass every deny). Keyword rules match whole words ("popular" no longer denies `*POP*`).
- AI Setup's merge logic moved out of the dialog into a tested `AiSetupMerger`; the change list it shows is unchanged.
